# Personal Projects Repository

This repository contains a collection of programming projects spanning various domains including artificial intelligence, machine learning, algorithms, web development, and systems programming. Each project demonstrates different programming concepts and techniques implemented across multiple languages including Python, C, and web technologies.

## Project Categories

### Artificial Intelligence & Machine Learning

**AI_tictactoe**
- Implementation of an AI agent that plays Tic-Tac-Toe optimally using minimax algorithm
- Built with Python and Pygame for graphical interface
- Demonstrates game theory and adversarial search algorithms

**RL_nim**
- Reinforcement learning model that learns to play the game of Nim
- Uses Q-learning algorithm to develop optimal strategies
- Showcases machine learning principles and reinforcement learning techniques

**GCN_citations_network**
- Graph Convolutional Network implementation for analyzing citation networks
- Demonstrates deep learning applications in graph-based data

**traffic**
- Neural network for traffic sign classification using the German Traffic Sign Recognition Benchmark (GTSRB) dataset
- Implements convolutional neural networks for computer vision tasks

### Algorithm Implementations

**SSIM**
- Python implementation of the Structural Similarity Index Measure (SSIM) algorithm from 2004
- Used for measuring perceptual similarity between images
- Includes comparative analysis of different upscaling software solutions

**DNA**
- DNA sequence analysis program that matches DNA profiles from a database
- Implements string matching algorithms and statistical analysis
- Processes Short Tandem Repeat (STR) sequences for identification

**degrees**
- Implementation of the "Six Degrees of Kevin Bacon" concept
- Uses breadth-first search to find connections between actors
- Demonstrates graph traversal algorithms

**crossword**
- Crossword puzzle generator using constraint satisfaction problems
- Implements backtracking algorithms and constraint propagation
- Generates valid crossword layouts with given word lists

**knights**
- Logic puzzle solver for Knights and Knaves problems
- Uses propositional logic and model checking
- Demonstrates automated reasoning techniques

**minesweeper**
- Minesweeper game implementation with AI solver
- Includes both playable game and intelligent agent
- Uses propositional logic for safe move determination

### Games & Simulations

**hangman**
- Classic word guessing game implementation
- Features word selection and game state management
- Demonstrates basic game development concepts

**mastermind**
- Recreation of the classic code-breaking game
- Implements game logic and scoring mechanisms
- Features pattern matching and feedback systems

### Web Applications

**birthdays**
- Flask web application for managing birthday records
- Includes SQLite database integration and HTML templating
- Demonstrates full-stack web development principles

### Systems Programming (C)

**inheritance**
- Simulation of genetic inheritance patterns
- Models allele distribution across generations
- Demonstrates C programming and probability concepts

**runoff**
- Implementation of ranked-choice voting system simulation
- Processes election data and determines winners through elimination rounds
- Showcases algorithm implementation and data structure manipulation

## Technical Stack

- **Languages**: Python, C, HTML, CSS, JavaScript
- **Frameworks**: Flask, Pygame
- **Libraries**: NumPy, scikit-image, TensorFlow/PyTorch (where applicable)
- **Databases**: SQLite

## Getting Started

Each project directory contains its own README or documentation with specific setup instructions. Most Python projects include a `requirements.txt` file for dependency management.

### Prerequisites

- Python 3.x for Python-based projects
- GCC compiler for C programs
- Web browser for web applications
- Various Python libraries (listed in individual project requirements)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/lorenzocaputi/Projects.git
   ```

2. Navigate to specific project directories for detailed setup instructions

3. Install required dependencies for Python projects:
   ```bash
   pip install -r requirements.txt
   ```

## Project Structure

Each project is contained within its own directory and includes:
- Source code files
- Documentation (README files where applicable)
- Required assets (fonts, images, data files)
- Dependencies specification
- Example inputs/outputs where relevant
